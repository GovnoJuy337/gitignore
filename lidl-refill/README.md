# Lidl Refill

Android-приложение: следит за остатком мобильного интернета и само шлёт SMS «Refill», когда остаток падает ниже порога.

Сборка: GitHub → Actions → «Build Lidl Refill APK» → Run workflow → скачать артефакт `app-debug.apk`.

Как работает: ты один раз вводишь текущий остаток МБ; дальше приложение считает мобильный трафик через `NetworkStatsManager`
(нужен доступ «Статистика использования»), и при остатке ≤ порога отправляет SMS. После отправки считает, что пришло +N МБ.
Оценка приблизительная — при расхождении с оператором просто перезапусти с новым остатком.
