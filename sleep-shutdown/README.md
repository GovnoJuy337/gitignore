# Выключение ПК, когда уснул

Основной вариант — `sleepwatch.ps1`: ночью, если 40 мин нет ввода, показывает «Ты не спишь?» на 90 с.
Шевельнул мышью — отмена; нет реакции — выключение (ещё 30 с, отмена `shutdown /a`).
Работает и при полноэкранном фильме, браслет и телефон не нужны.

1. Скопируй папку на ПК, например `C:\sleep-shutdown`.
2. Тест (ничего не выключит): `powershell -ExecutionPolicy Bypass -File sleepwatch.ps1 -IdleMinutes 1 -NightStart 0 -NightEnd 24 -ConfirmSeconds 20 -DryRun`
   Не трогай мышь минуту — должно появиться окно с отсчётом.
3. Установка: `powershell -ExecutionPolicy Bypass -File install.ps1`
4. Параметры (ночное окно, минуты простоя) меняются в `install.ps1` через аргументы или значения по умолчанию в `sleepwatch.ps1`.

`listener.ps1` — необязательный приёмник HTTP-команды с телефона (нужны правило брандмауэра на порт 8765 и токен).
